# Frutas Orfa

Sitio web estático para el catálogo y pedidos de Frutas Orfa.

## Abrir en Visual Studio Code

1. Abre Visual Studio Code.
2. Ve a **Archivo > Abrir carpeta**.
3. Selecciona la carpeta `frutas-orfa`.
4. Abre `index.html` en el navegador o usa la extensión Live Server.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta, incluida la carpeta `assets`.
3. En el repositorio, ve a **Settings > Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main`, la carpeta `/ (root)` y guarda.

GitHub mostrará el enlace público cuando termine la publicación.
